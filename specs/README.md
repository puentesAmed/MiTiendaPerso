# Especificaciones de MiTiendaPerso

Cada cambio relevante requiere una SPEC antes de su implementación.

Una SPEC debe definir:

* objetivo;
* alcance;
* fuera de alcance;
* criterios de aceptación;
* validación.

Las SPEC se numeran secuencialmente y siguen este formato:

```text
specs/NNN-nombre/SPEC.md
```

Una SPEC cerrada no debe ampliarse silenciosamente. Cualquier alcance adicional debe documentarse y planificarse en una SPEC posterior.
